# Multiplayer m,n,k-game

Came up with this idea way long ago as multiplayer tictactoe.

Plan is to get some alphago/alphazero style RL spam in here, but might not be complex enough since mcts is handling this quite well.

dependency: raylib for UI

## How to run
make run -> run default

make -> builds at ./build/mnk_game

usage: mnk_game [--launch <settings.yaml>] | --train <settings.yaml> <num_games>
